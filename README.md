# 📌 Animated To-Do List (Full Stack)

A modern, animated, full-stack To-Do List application built with **HTML, CSS, JavaScript, Node.js, and JWT authentication**.
This project focuses on **UI/UX design, smooth animations, and real-world backend integration**.

---

## ✨ Features

### 🎨 Frontend

* Glassmorphism UI design
* Smooth task animations (add / complete / delete)
* Drag & drop task reordering
* Dark / Light mode toggle
* Responsive design for all devices
* Task filters (All / Active / Completed)

### ⚙️ Backend

* Node.js + Express REST API
* User authentication (JWT)
* Password hashing (bcrypt)
* Task CRUD operations via API

### 💾 Data Handling

* LocalStorage fallback (frontend mode)
* API-based persistent storage (backend mode)

---

## 🛠️ Tech Stack

* HTML5
* CSS3 (Glassmorphism + Animations)
* JavaScript (ES6+)
* Node.js
* Express.js
* JWT Authentication
* bcrypt.js

## 🚀 Getting Started

### 1️⃣ Clone the repository

```bash
git clone https://github.com/your-username/animated-todo-list.git
```

---

### 2️⃣ Install backend dependencies

```bash
cd backend
npm install
```

---

### 3️⃣ Run the server

```bash
node server.js
```

Server runs on:

```
http://localhost:3000
```

---

### 4️⃣ Open frontend

Simply open:

```
index.html
```
